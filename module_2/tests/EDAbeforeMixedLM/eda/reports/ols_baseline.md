## 해석

- `log_N` 계수 ≈ (b-1): 멱함수 `ratio = a × N^(b-1)`에서 b 추정
  - b = 1 → log_N 계수 = 0 → 완전 선형 (ratio≈1)
  - b < 1 → log_N 계수 < 0 → 규모의 경제 (대량 시 덜 필요 — 양념류 예상)
  - b > 1 → log_N 계수 > 0 → 규모 비례 이상 증가
- 잔차 플롯에서 group_type별 군집 패턴 → MixedLM 필요성 근거
- MixedLM 비교는 이 태스크 범위 외
