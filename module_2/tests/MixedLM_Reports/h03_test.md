# H0₃ 검정 — 조리방법 대분류 간 b 차이

**생성일:** 2026-03-20
**귀무가설 H0₃:** 조리방법 대분류(group_type) 간 스케일링 지수 b 차이 없음
**대립가설 H1₃:** 최소 하나의 group_type에서 b가 다름
**방법:** cooking_method(세분류, n≥10) 서브셋 OLS → group_type별 b 묶음 → one-way ANOVA

---

## group_type별 b 값 (n≥10 세분류 기반)

- **비가열**: [np.float64(0.9037), np.float64(0.6055)]
- **습열**: [np.float64(1.0383), np.float64(1.2016), np.float64(1.0138), np.float64(0.5794), np.float64(1.082)]
- **건열**: [np.float64(1.0648), np.float64(1.1404), np.float64(0.1099)]

---

## 검정 결과

| 통계량 | 값 |
|:-------|---:|
| F 통계량 | 0.4497 |
| p값 | 6.5504e-01 |
| 판정 (α=0.05) | 채택 (그룹 간 b 차이 유의하지 않음) |
