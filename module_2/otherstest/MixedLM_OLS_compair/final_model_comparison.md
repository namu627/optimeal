## 3. 채택 모델 결정

**채택 모델: MixedLM B안 (단순 랜덤효과)**

### 사전 선언 채택 기준 적용 결과

```
수렴 성공 AND AIC(A안) < AIC(B안) → A안 채택
수렴 성공 AND AIC(B안) ≤ AIC(A안) AND |b_A - b_B| < 0.05 → B안 채택 (간결성 우선)  ← 해당
수렴 성공 AND AIC(B안) ≤ AIC(A안) AND |b_A - b_B| ≥ 0.05 → A안 채택 (정확성 우선)
A안 수렴 실패 → B안 단독 채택
```

| 판단 항목 | 값 | 충족 여부 |
|-----------|-----|---------|
| A안·B안 수렴 성공 | 경고 0건 | ✅ |
| \|b_A - b_B\| | 0.0060 | < 0.05 ✅ |
| 적용 기준 | **B안 채택 (간결성 우선)** | — |

## 6. 논문 방법론 기재 권장 문구

> "OLS 기준선 대비 MixedLM A안의 AIC가 67.13 감소하여(OLS: 1909.71 → MixedLM A안: 1842.58, 동일 n=950) 랜덤효과 도입의 통계적 정당성을 확인하였다. 최종 채택 모델은 사전 선언된 간결성 기준(|b_A − b_B| = 0.006 < 0.05)에 따라 MixedLM B안(단순 랜덤효과, n=607)으로 결정하였다. A안과 B안의 n 차이(950 vs 607)로 인해 양 모델의 AIC 직접 비교는 수행하지 않았다."
