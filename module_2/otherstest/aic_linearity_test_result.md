## 해석

- **ΔAIC 해석**: AIC(B) - AIC(A) = -2.6036
  - ΔAIC < -2: 비선형 모델(B)이 선형 모델(A)보다 유의미하게 적합함
  - ΔAIC ≥ -2: 두 모델 간 실질적 차이 없음

- **LRT 해석**: log_N 항 추가가 모델 적합도를 통계적으로 유의하게 개선하는지 검증
  - p < 0.05 → 비선형성 통계적으로 지지됨
  - p ≥ 0.05 → 비선형성 통계적으로 유의하지 않음
