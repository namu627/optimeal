# 영양사 평가 루브릭 v1.0

**작성일:** 2026-04-05
**기준 문서:** ADR-002 v3, FR-09, PRD v1.5
**상태:**  확정 (4월 3주차 이전 Cohen's Kappa 측정 필수)

---

## 1. 평가 개요

| 항목 | 내용 |
|------|------|
| 평가 대상 | Rule-based 엔진이 생성한 대규모 레시피 |
| 평가자 수 | 최소 2명 (영양사 자격증 보유자) |
| 평가 방식 | 독립 평가 후 합의 (피드백 미교환 상태) |
| 판정 기준 | 루브릭 3항목 평균 ≥ 4.00점 → "상용가능" |
| 피드백 회차 | 총 5회차 (5/4 ~ 5/19) |

## 2. 루브릭 평가 기준표 (5점 척도)

### 항목 1: 맛·간 적절성

| 점수 | 기준 |
|:----:|------|
| 5 | 간이 적절하고 맛의 균형이 뛰어남. 현장 즉시 적용 가능 |
| 4 | 간이 대체로 적절. 미세 조정(±5% 이하) 수준의 수정이면 충분 |
| 3 | 간이 다소 어긋남(예: 짜거나 싱거움). 조미료 1~2종의 10~20% 수준 수정 필요 |
| 2 | 주요 조미료(소금, 간장, 설탕 등)의 양이 현저히 부적절. 30% 이상 수정 필요 |
| 1 | 섭취 불가 수준의 간. 레시피 전면 재산출 필요 |

### 항목 2: 조리 실현 가능성

| 점수 | 기준 |
|:----:|------|
| 5 | 지시된 재료량·조리 순서로 현장 조리 완전 실현 가능 |
| 4 | 조리 실현 가능. 현장 조리사가 소폭 조정(기물 크기 등) 필요 수준 |
| 3 | 재료량의 부분적 비현실성(예: 냄비 용량 초과 가능성). 조리법 수정 수반 필요 |
| 2 | 지시된 투입량으로 조리 자체가 어려움. 분할 조리 등 대규모 변경 필요 |
| 1 | 현장 조리 불가. 물리적으로 실현 불가능한 수량 포함 |

### 항목 3: 대량 조리 현장 적합성

| 점수 | 기준 |
|:----:|------|
| 5 | 대량 급식 환경(100인분+)에 최적화. 재료 수급·관리·배식 모두 적합 |
| 4 | 대부분 적합. 현장 관행과 소폭 차이는 있으나 허용 범위 이내 |
| 3 | 일부 재료의 대량 조달 어려움 또는 현장 관행과 현저히 다른 투입량 |
| 2 | 급식소 운영 비용·물리적 제약(냉장 보관 한계 등) 문제 발생 가능 |
| 1 | 급식 현장 적용 불가 수준 |

## 3. 종합 판정

```
rubric_avg = (항목1 + 항목2 + 항목3) / 3

rubric_avg ≥ 4.00  →  "상용가능"  (overall_rating = '상용가능')
2.50 ≤ rubric_avg < 4.00  →  "수정필요"  (overall_rating = '수정필요')
rubric_avg < 2.50  →  "부적합"  (overall_rating = '부적합')
```

**완료 기준:** 동일 조리 그룹에서 연속 10개 레시피 rubric_avg ≥ 4.00점.

## 4. Cohen's Kappa 측정 방법

### 목적
- 단일 평가자 의존 리스크 제거 (PRD v1.5 리스크 항목)
- 논문 방어: 평가자 간 신뢰도 정량화

### 측정 절차

1. **보정용 세트 선정**: 1회차(볶음) 시작 전, 조리방법 혼합 10개 레시피를 보정용으로 선정
2. **독립 평가**: 두 평가자가 서로 결과를 공유하지 않고 각자 10개 레시피를 평가
3. **계산 방법**: Python `sklearn.metrics.cohen_kappa_score` 또는 아래 수식 직접 계산

```python
from sklearn.metrics import cohen_kappa_score

# 항목별 점수(1~5)를 기반으로 overall_rating(상용가능/수정필요/부적합)으로 변환 후 계산
# 또는 연속형 가중치 Kappa (weights='quadratic') 사용
kappa = cohen_kappa_score(rater1_ratings, rater2_ratings, weights='quadratic')
```

4. **기준 및 대응:**

| Kappa 값 | 해석 | 대응 |
|:--------:|------|------|
| ≥ 0.8 | 거의 완전한 일치 | 정상 진행 |
| 0.6 ~ 0.79 | 상당한 일치 (**목표 기준**) | 정상 진행 |
| 0.4 ~ 0.59 | 보통 일치 | 루브릭 기준 재논의 후 2차 측정 |
| < 0.4 | 낮은 일치 | 평가 기준 재정의 필수. 피드백 회차 연기 |

**목표:** Kappa ≥ 0.6 (PRD 리스크 항목)

### 측정 시점
- **4월 3주차(4/19) 이전 필수** 완료 (PRD v1.5 명시)
- 보정 세트 평가 완료 후 팀 회의에서 Kappa 값 검토
- Kappa < 0.6인 경우: 루브릭 항목별 기준 문구 구체화 후 재측정

### 논문 기재 의무
```
"두 명의 등록 영양사가 독립적으로 평가하였으며, Cohen's weighted Kappa = [값]으로
평가자 간 신뢰도가 [해석] 수준임을 확인하였다 (Landis & Koch, 1977)."
```

## 5. 피드백 회차별 평가 대상 레시피 선정

**원칙:**
- 회차당 10개 레시피 (실현 불가 시 최소 8개)
- 회차 내 레시피는 동일 조리방법(group_type + 세부 조리방법) 집중
- 4회차(혼합 조리법)는 보조 조리방법 존재 레시피

| 회차 | 날짜 | 대상 조리방법 | 비고 |
|:----:|------|--------------|------|
| 1회차 | 5/4 | 볶기 (dry_heat) | 양념류 b 보정 주목적 |
| 2회차 | 5/8 | 구이·부침 (dry_heat) + 끓이기 (moist_heat) | 건열/습열 각 5개 |
| 3회차 | 5/12 | 찜·조림 (moist_heat) + 비가열 무침 (no_heat) | 비가열 30쌍 한계 인지 |
| 4회차 | 5/15 | 혼합 조리법 (secondary_method_id 존재) | 복합 보정 |
| 5회차 | 5/19 | 전체 재검증 (회차별 각 2개) | 최종 파라미터 확정 |

### 회차별 레시피 목록 확정 절차

1. **D-7(피드백일 7일 전)**: 해당 회차 조리방법 레시피 후보 목록 영양사에게 사전 전달
2. **D-3**: 영양사 확인 후 평가 대상 10개 확정
3. **D-0(피드백일)**: Rule-based 엔진으로 대규모 변환본 생성 → 평가 실시

### 비가열 그룹 주의사항

비가열(무침) 그룹은 총 30쌍으로 ADR-002 v4 기준(≥50쌍) 미달.
3회차 피드백 시 b 추정 불확실성이 크므로 피드백 보정 폭을 보수적으로 적용한다.
논문 한계 절에 "비가열 n=30으로 피드백 보정 b의 신뢰도가 타 조리방법 대비 낮음" 명시 의무.
