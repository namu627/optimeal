# H0₁ 검정 — paired t-test 논문 기재용

**작성일:** 2026-03-27
**기반 파일:** cv_results_final.md (MixedLM + small_recipe_id 재실행 결과)
**채택 보고 방식:** 단측 검정(alternative='less'), t 통계량 + 방향(t > 0) 명시

---

## 1. 검정 설계

| 항목 | 내용 |
|------|------|
| 검정 방법 | Paired t-test (대응표본 t-검정) |
| 표본 단위 | 5개 GroupKFold 폴드 |
| 변수 a | 멱함수 모델 MAPE (폴드별) |
| 변수 b | 선형 모델(b=1) MAPE (폴드별) |
| 귀무가설 H0₁ | mean(MAPE_멱함수 − MAPE_선형) = 0 |
| 대립가설 H1₁ | mean(MAPE_멱함수 − MAPE_선형) < 0 (멱함수가 더 작음) |
| 유의수준 α | 0.05 |
| `scipy` 호출 | `stats.ttest_rel(mape_power, mape_linear, alternative='less')` |

---

## 2. 입력 데이터

| Fold | MAPE 멱함수 (%) | MAPE 선형 (%) | 차이 (멱함수 − 선형) |
|:----:|---------------:|---------------:|--------------------:|
| 1    | 57.38          | 56.71          | +0.67               |
| 2    | 82.41          | 67.78          | +14.63              |
| 3    | 80.80          | 69.08          | +11.72              |
| 4    | 84.37          | 45.05          | +39.32              |
| 5    | 78.80          | 88.28          | −9.48               |
| **평균** | **76.75** | **65.38**  | **+11.37**          |

---

## 3. 통계량 계산

| 통계량 | 계산 과정 | 값 |
|--------|-----------|-----|
| 평균 차이 (d̄) | (0.67 + 14.63 + 11.72 + 39.32 − 9.48) / 5 | **+11.372** |
| 차이 표준편차 (s_d) | √(Σ(dᵢ − d̄)² / (n−1)), n=5 | **18.309** |
| 표준오차 (SE) | s_d / √n = 18.309 / √5 | **8.190** |
| **t 통계량** | d̄ / SE = 11.372 / 8.190 | **+1.388** |
| 자유도 (df) | n − 1 = 5 − 1 | **4** |
| 양측 p-value | 2 × P(T₄ > 1.388) | 0.2374 |
| **단측 p-value** (alternative='less') | P(T₄ ≤ +1.388) = 1 − (0.2374/2) | **0.8813** |

---

## 4. 검정 결과

| 항목 | 값 |
|------|-----|
| **t 통계량** | **+1.388 (t > 0 → 멱함수 MAPE > 선형 MAPE 방향)** |
| 자유도 (df) | 4 |
| 단측 p-value (alternative='less') | **0.881** |
| H0₁ 기각 여부 | **기각 불가 (p = 0.881 ≫ 0.05)** |

> **방향 해설:** `alternative='less'`는 H1: mean(MAPE_멱함수 − MAPE_선형) < 0을 검정한다. t = +1.388 > 0이므로 실제 차이 방향이 H1과 반대다. 독자는 t의 부호만으로 검정 결론을 즉시 확인할 수 있다.

---

## 5. 해석

**검정 방향 주의**

t = +1.388 > 0이다. 즉, 5개 폴드 평균에서 멱함수 MAPE(76.75%)가 선형 MAPE(65.38%)보다 **높다**. 대립가설 H1₁이 상정한 방향(멱함수 < 선형)과 **반대 방향**의 결과가 나왔다. 단측 p=0.881은 이를 수치로 확인한다.

**원인 — 데이터 구조적 한계 (변경 불가)**

| 한계 요인 | 설명 |
|-----------|------|
| N 고유값 7개 | N = 80, 100, 120, 130, 210, 260, 300인. 멱함수의 비선형 이점은 N 범위가 넓을수록 드러나는데 현재 데이터가 이를 지지하지 못함 |
| 단일 b 적용 | CV는 전체 데이터에 단일 b를 적용해 MAPE 계산. 실제 엔진은 (group_type × ingredient_category) 셀별 개별 b 사용 (양념류 b≈0.35, 주재료 b≈1.15). 셀별 차이가 평균화되면서 MAPE 상승 |
| 폴드 수 부족 | n_folds = 5로 paired t-test 검정력이 낮음 |

**논문에서의 위치**

CV MAPE 비교는 주 근거가 아닌 **방법론 한계 절**에 기재한다. 멱함수 채택의 주 근거는 **MixedLM 전체 데이터 결과** (b = 0.6163, 95% CI [0.261, 0.972], p < 0.05)이다.

---

## 6. 논문 기재 권장 문구

### 방법론 절 (Methods)

> GroupKFold 교차검증(n_splits=5, 분할 단위: base_recipe_id)을 통해 멱함수 모델과 선형 모델(b=1)의 MAPE를 폴드별로 산출하고, 대응표본 t-검정(단측, H1: MAPE_멱함수 < MAPE_선형, `scipy.stats.ttest_rel(..., alternative='less')`)으로 비교하였다.

### 결과 절 (Results)

> 교차검증 결과 멱함수 모델의 평균 MAPE는 76.75%, 선형 모델은 65.38%로 나타났다. 대응표본 t-검정(t(4) = +1.39, p = 0.881, 단측)에서 t > 0으로 관측 방향이 대립가설과 반대였으며, 멱함수 모델이 선형 모델 대비 MAPE를 유의하게 낮추지 못하였다.

### 한계 절 (Limitations)

> 교차검증에서 멱함수 모델이 선형 모델 대비 유의한 MAPE 개선을 보이지 않은 것(t(4) = +1.39, p = 0.881, 단측; t > 0으로 관측 방향이 H1과 반대)은 세 가지 구조적 한계에 기인한다: (1) N 고유값이 7개(80–300인)로 제한되어 비선형 스케일링 효과의 검출력이 낮음, (2) 교차검증에서 단일 b를 적용하였으나 실제 엔진은 셀별 개별 b를 사용함, (3) 폴드 수 5개로 paired t-test의 검정력이 낮음. 멱함수 채택의 주 근거는 전체 데이터 기반 MixedLM 결과(b = 0.6163, 95% CI [0.261, 0.972], p < 0.05)로 별도 보고된다.

## 7. 검정 방식별 비교 및 채택 근거

| 검정 방식 | t 통계량 | df | p-value | H1 방향 일치 여부 |
|-----------|:--------:|:--:|:-------:|:---:|
| 양측 (cv_results_final.md 원본) | +1.388 | 4 | 0.237 | — (방향 미지정) |
| **단측 alternative='less' (채택)** | **+1.388** | **4** | **0.881** | **불일치 (t > 0)** |

**채택 이유**

H1₁이 "멱함수 MAPE < 선형 MAPE"로 방향이 사전 선언된 단측 가설이므로 `alternative='less'`가 방법론적으로 올바르다. t = +1.388 > 0은 관측 결과가 H1 방향과 반대임을 직접 보여주며, 독자는 t 부호만으로 결론을 즉시 검증할 수 있다. 양측 p=0.237을 단측 가설과 함께 보고하면 방법론 불일치가 발생한다.

**수치 관계**

```
t > 0  →  p(alternative='less') = 1 − p(two-sided)/2 = 1 − 0.237/2 = 0.881
```

어느 방식이든 H0₁ 기각 불가라는 결론은 동일하나, 논문에는 단측 p=0.881과 t=+1.388을 함께 기재하여 방향 정보를 투명하게 제공한다.
