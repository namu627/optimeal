## 3. 연구 방법 (Methods)

### 3.5 교차검증 및 H0₁ 통계 검정

멱함수 모델과 선형 기준 모델 간 예측 성능 차이를 검증하기 위해 GroupKFold 교차검증과 대응표본 t-검정을 실시하였다.

**교차검증 설계.** GroupKFold 교차검증(n_splits=5)을 적용하였으며, 분할 단위는 `base_recipe_id`로 설정하였다. 동일 메뉴의 소규모-대규모 레시피 쌍이 학습 폴드와 검증 폴드에 동시 포함될 경우 데이터 누수(data leakage)가 발생하므로, 이를 방지하기 위해 일반 KFold 대신 GroupKFold를 사용하였다(ADR-002 v2).

**성능 지표.** 각 폴드에서 멱함수 모델과 선형 모델(b=1, ratio=1 고정)의 MAPE(Mean Absolute Percentage Error)를 산출하였다.

**통계 검정.** GroupKFold 교차검증(n_splits=5, 분할 단위: base_recipe_id)을 통해 멱함수 모델과 선형 모델(b=1)의 MAPE를 폴드별로 산출하고, 대응표본 t-검정(단측, H1: MAPE_멱함수 < MAPE_선형, `scipy.stats.ttest_rel(..., alternative='less')`)으로 비교하였다.

| 항목 | 내용 |
|------|------|
| 귀무가설 H0₁ | mean(MAPE_멱함수 − MAPE_선형) = 0 |
| 대립가설 H1₁ | mean(MAPE_멱함수 − MAPE_선형) < 0 (멱함수가 더 작음) |
| 유의수준 α | 0.05 |
| 검정 방법 | Paired t-test, 단측(alternative='less') |
| 표본 단위 | 5개 GroupKFold 폴드 |

## 4. 연구 결과 (Results)

### 4.3 교차검증 기반 H0₁ 검정 결과

GroupKFold 교차검증 5개 폴드의 MAPE 결과는 다음과 같다.

| Fold | MAPE 멱함수 (%) | MAPE 선형 (%) | 차이 (멱함수 − 선형) |
|:----:|---------------:|---------------:|--------------------:|
| 1    | 57.38          | 56.71          | +0.67               |
| 2    | 82.41          | 67.78          | +14.63              |
| 3    | 80.80          | 69.08          | +11.72              |
| 4    | 84.37          | 45.05          | +39.32              |
| 5    | 78.80          | 88.28          | −9.48               |
| **평균** | **76.75** | **65.38**  | **+11.37**          |

교차검증 결과 멱함수 모델의 평균 MAPE는 76.75%, 선형 모델은 65.38%로 나타났다. 대응표본 t-검정(t(4) = +1.39, p = 0.881, 단측)에서 t > 0으로 관측 방향이 대립가설과 반대였으며, 멱함수 모델이 선형 모델 대비 MAPE를 유의하게 낮추지 못하였다.

| 통계량 | 값 |
|--------|-----|
| 평균 차이 (d̄) | +11.372 |
| 차이 표준편차 (s_d) | 18.309 |
| **t 통계량** | **+1.388 (t > 0: 멱함수 MAPE > 선형 MAPE)** |
| 자유도 (df) | 4 |
| 단측 p-value (alternative='less') | **0.881** |
| **H0₁ 기각 여부** | **기각 불가 (p = 0.881 ≫ 0.05)** |

따라서 H0₁을 기각할 수 없으며, 교차검증 단독으로는 멱함수 모델의 우위를 통계적으로 입증하지 못하였다. 그러나 이는 데이터 구조적 한계에 기인하는 것으로, 멱함수 채택의 주 근거인 전체 데이터 기반 MixedLM 결과(b = 0.6163, 95% CI [0.261, 0.972], p < 0.05)는 별도의 절에서 보고된다.

## 5. 한계 및 논의 (Limitations)

### 5.1 교차검증 기반 H0₁ 기각 불가에 관한 구조적 한계

교차검증에서 멱함수 모델이 선형 모델 대비 유의한 MAPE 개선을 보이지 않은 것(t(4) = +1.39, p = 0.881, 단측; t > 0으로 관측 방향이 H1과 반대)은 세 가지 구조적 한계에 기인한다.

**첫째, N 고유값의 제한이다.** 본 연구의 데이터셋에서 목표 인원수(N)의 고유값은 총 7종(N = 80, 100, 120, 130, 210, 260, 300인)에 불과하다. 멱함수 모델의 비선형 스케일링 효과는 N의 범위가 넓을수록, 즉 소규모(예: 10인)와 대규모(예: 500인)가 공존할 때 그 차별성이 명확하게 드러난다. 현재 데이터셋은 모두 80인 이상의 대규모 관측에 한정되어 있어, N 변동 범위가 좁고 이로 인해 멱함수의 비선형 이점이 교차검증 MAPE에 반영되지 않았다.

**둘째, 교차검증에서의 단일 b 적용 문제이다.** 교차검증에서는 전체 데이터에 단일 b 값을 적용하여 MAPE를 산출하였다. 그러나 실제 Rule-based 엔진은 (group_type × ingredient_category) 셀별로 개별 b 값을 사용한다(예: 양념류 b ≈ 0.35, 주재료 b ≈ 1.15). 재료 카테고리별로 b가 상이함에도 불구하고 단일 평균 b를 적용하면, 셀별 차이가 평균화되어 멱함수 모델의 예측 정확도가 실제보다 낮게 측정된다. 따라서 교차검증 MAPE는 실제 엔진 성능을 과소평가한다.

**셋째, 폴드 수 부족으로 인한 검정력 저하이다.** 대응표본 t-검정은 폴드별 MAPE 차이를 표본으로 사용하므로, 폴드 수가 곧 표본 크기(n = 5)가 된다. 자유도 4에서의 paired t-test는 검정력이 낮아, 실질적인 차이가 존재하더라도 이를 통계적으로 검출하기 어렵다. 폴드 수를 늘리면 검정력이 향상되지만, GroupKFold 특성상 데이터 규모와 그룹 수에 의해 실행 가능한 폴드 수가 제약된다.

**멱함수 채택의 근거.** 위의 구조적 한계로 인해 교차검증 기반 H0₁ 검정은 멱함수 모델의 우위를 입증하는 주 근거로 사용되지 않는다. 멱함수 채택의 주 근거는 전체 데이터를 활용한 MixedLM 분석 결과(b = 0.6163, SE = 0.1814, 95% CI [0.261, 0.972], p < 0.05, n = 607, AIC = 1262.87)이며, 이는 선형 모델(b = 1) 대비 통계적으로 유의한 비선형 효과를 확인한다. 교차검증 결과는 방법론의 투명성을 위해 한계와 함께 보고하며, 향후 N 범위 확대 및 데이터 증가에 따라 재검증이 필요하다.
