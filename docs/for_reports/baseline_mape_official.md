- **모델:** 단순 선형 (ratio = 1, b = 1 고정)
- **수식:** `Y_pred = base_amount × N`
- **의미:** 스케일링 보정 없이 1인분량에 인원수를 곱한 값이 예측값

- **ratio 필터:** [0.2, 3.0] — ADR 확정값 (2026-03-20), 변경 금지
