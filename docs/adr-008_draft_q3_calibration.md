## 1. 배경 (Context)

ADR-006(1D ResNet)·ADR-007(NN_v2+lookup 하이브리드)은 모듈 2의 핵심 산출물을 "선형 대비 정확한 비선형 스케일링 엔진"으로 위치시켰다. 그러나 2026-06-27 실측 6루프 검증에서 다음이 확정되었다:

1. **기존 모든 NN/lookup MAPE는 합성 타겟 대 합성 타겟 비교였다.** 학습 타겟 `Y=base×N^b_feedback` 자체가 결정론 공식이므로, NN은 그 공식을 모방할 뿐이고 MAPE는 근사 오차이지 예측력이 아니었다.
2. **실측 Y(`df_B.csv`)로 직접 평가하면 선형이 사실상 최선이다.** (실측 OOS MAPE: 선형 65.4%, 유연 GBM 66.8%, OOS R²=0.06.)
3. **N이 식별 불가능하다.** 607행 중 570행(94%)이 N=100. N=80 11행만 제거해도 b가 0.625→0.761로 점프하며 95%CI가 1.0(선형)을 포함한다. "비선형 스케일링 법칙"의 b 점추정은 소수 점에 의존한다.
4. **분산의 96%가 (group_type×category) 셀로 설명되지 않는다.** 레시피별/재료별 고유 보정값이며 어떤 피처로도 예측 불가.
5. **메트릭 착시·운영 위험.** MAPE를 낮추는 모델(카테고리 b)은 WAPE에서 꼴찌이고 −20.8% 과소예측(현장 결식 위험)이다. MAPE·WAPE 동시 우위 모델은 존재하지 않는다.
6. **범위 단서 — "도메인 불가"가 아니라 "현 데이터로 불가"** (유사 도메인 서베이, `scaling_domains_survey.md`): 멱함수 양 스케일업+랜덤효과는 약물 알로메트리(b≈0.75, NLME)·공학 6/10 비용법칙(b≈0.6)·생물 알로메트리(b=0.75)가 푸는 표준 구조다. 이들 분야의 확립된 발견 — "고변동(BSV)→지수 식별 불가"(파마코메트릭스), "10배 범위 초과 외삽 금지"(6/10법칙), "범위 분할 시 지수가 0.667↔0.754로 갈림 = 식별 인공물"(Kleiber) — 이 **우리 데이터 조건(N 변동 부재)에서 그대로 발현**된 것. 즉 본 음성 결과는 고립된 실패가 아니라 **스케일링 문헌과 정합하는 식별성 한계**.

결론(Q1/Q2/Q3): **현 데이터로는 모델로도(Q1=No) 메트릭으로도(Q2=성능 불변) 예측 정확도를 끌어올릴 수 없다.** 원인은 데이터 인프라(N 식별불가 + 비구조 노이즈 + 시대불일치)이며, 추가 데이터 수집은 불가 가정이다. (3단 주장: 원리상 가능·사례 있음 / 조건은 넓은 스케일 범위·통제 데이터 / 한국 레시피 인프라로 현재 불가.)

## 2. 결정 (Decision) — 초안

### 2.1 학술 기여를 두 갈래로 분리·축소

| 기여 | 내용 | 평가 축 |
|------|------|---------|
| **(A) 통계** | 대량조리 스케일링에 **비선형 관계가 통계적으로 존재**함을 MixedLM으로 입증 (b≠1, ΔAIC=−67.13, LRT p=0.032). | 존재 입증 (정확도 아님) |
| **(B) 시스템** | 예측이 **현 데이터로 불가능한**(원리상 가능하나 데이터 인프라 결여 — `scaling_domains_survey.md`) 도메인에서, **영양사 보정을 정답으로 누적·수렴시키는 human-in-the-loop 캘리브레이션 도구**를 설계·구현. | 수렴성·운영가능성 (정확도 아님) |

(A)는 **반드시 식별성 한계를 방법론에 명시**한다: "b 점추정은 N 표본이 N=100에 집중(94%)되어 식별성에 제약이 있으며, 비선형의 *방향성·존재*는 지지되나 *크기*의 신뢰구간은 넓다."

### 2.2 엔진 구조 재정의 — 예측기 → 캘리브레이션 기판

```
[Cold-start] 초기 추정 = 선형(b=1) 또는 카테고리 b   ← "정확한 예측"이 아닌 "출발점"으로 표기, 신뢰도 플래그 동반
        │
        ▼
[영양사 사용] 재료별 실투입량 보정 Δ_g 입력
        │
        ▼
[캘리브레이션 레이어] (업장 × 레시피 × 재료) 단위로 보정 누적
        │   갱신: ADR-003 EMA / 단순 이동평균 (feedback_update.py 재사용)
        ▼
[반복 사용] 해당 업장의 실측으로 수렴 → 다음 회차 추정 정확도 상승
```

- cold-start 기본값은 **선형(b=1)** 채택을 권고한다 (실측 최선, 무편향, 과소예측 위험 없음). 카테고리 b는 옵션으로 제공하되 −20.8% 과소편향을 표기.
- 캘리브레이션 단위는 **(레시피×재료)** 를 기본으로, 멀티 업장 확장 시 **(업장×레시피×재료)**.
- **CBR 참고 표시 (사례 기반 추론, retrieve+propose)**: 입력 화면 옆에 *주재료+부재료 집합이 유사한 과거 레시피*에서 영양사가 실제 보정한 양을 **참고 이력으로 표시**(출처·일시 명시). 자동 적용 금지(인간 판단). OOS에서 유사도 *자동* 적용은 실패했으나(재료풀링 73.6%>선형), *표시*는 decision-support이므로 무관 — 업계 관행 "75% 후 맛보고 조정"과 정합. 닻내림 위험 완화(분포/범위로 제시). 근거: `scaling_domains_survey.md` §3.

### 2.3 NN·하이브리드의 위상 강등

- NN v1/v2, ADR-007 하이브리드는 **운영 정확도 주장에서 제외**, 실험 기록·비교군으로 보존.
- ADR-006/007의 "NN이 lookup 대비 +2.01%p 우위" 등 *정확도* 표현은 합성 타겟 한정임을 명시하고 실측 주장에서 철회. 구조·코드는 삭제하지 않음.

### 2.4 평가 지표 재정의

| 단계 | 주 지표 |
|------|---------|
| Cold-start | 실측 OOS에서 선형 대비 **동등/약우위를 정직 보고**(과장 금지). MAPE·WAPE·MdAPE 병기 + 부호편향. |
| 캘리브레이션 | **회차별 수렴 속도, 영양사 보정량(Δ_g) 감소 추세, 승인율.** |

## 3. 가장 민감한 함의 — NFR-01 재정의 (팀·교수 동의 완료 2026-06-28)

PRD/요구사항의 **NFR-01 "선형 대비 20% 이상 정확도 개선, p<0.05"** 는 실측 기준으로 **달성 불가**로 판정되어, 본 ADR 승인과 함께 다음 개정이 **확정 반영되었다**:

- NFR-01을 "선형 대비 정확도 개선" → **"(A) 비선형 관계의 통계적 입증 + (B) 캘리브레이션 수렴성 입증"** 으로 교체. ✅
- FR-04/05/08의 성공 기준 재작성. PRD §11 성공지표·§12-1 외적타당성 한계 갱신. ✅

> ✅ 프로젝트 #1 필수 성공 지표의 변경 — 권성민·팀·지도교수 합의 완료(2026-06-28).

## 4. 근거 (Rationale)

- **현 데이터에서 예측 불가능성이 입증된 상황에서 정직한 산출물은 "예측기"가 아니라 "학습하는 도구"다.** 96% 비구조 잔차는 관측해 누적하는 human-in-the-loop만 흡수 가능하다. (도메인 자체는 학습 가능하나 데이터 인프라 결여 — `scaling_domains_survey.md`: 알로메트리·공정 스케일업의 확립된 식별성 한계와 정합.)
- **약점을 강점으로 전환**: "모델이 못 맞춘다"는 결과를, "현장 지식이 본질적으로 필요한 문제임을 실증하고 그 지식을 체계적으로 축적하는 시스템을 설계했다"로 재서술. 이는 음성 결과(negative result)의 정직한 학술 보고이자 시스템 기여.
- **통계 기여는 보존**: 비선형의 *존재*는 여전히 유효한 학술 주장(식별성 한계 부기).

## 5. 기각안 (Rejected Alternatives)

| 안 | 기각 사유 |
|----|-----------|
| 다른 랜덤효과 모델/베이지안 계층모형으로 재시도 | Q1 실증: 유연 GBM도 OOS에서 선형 못 이김(R²=0.06). 모델 종류는 병목 아님. |
| 메트릭 교체(WAPE/sMAPE 등)로 우위 주장 | Q2 실증: 메트릭마다 순위 뒤집힘. 예측 자체는 불변. |
| NN 합성타겟 MAPE를 그대로 논문 보고 | 순환 검증. 독립 ground truth 부재. |
| 현 NFR-01 유지하고 [0.5,2.0] 필터로 32.68% 보고 | ADR 확정 필터 [0.2,3.0] 위반. 헤드라인 숫자가 필터 선택에 의존. |
| "도메인 자체가 학습 불가"로 결론 | 서베이 반증: 알로메트리·6/10법칙·KitchenScale은 동일 구조를 학습함. 정확한 진술은 "현 데이터 인프라로 불가". |

## 6. 한계 (Limitations) — 정직 명시

1. **수렴성 미실증**: (레시피×재료) 셀이 실측에 각 1회만 등장 → 같은 업장 반복 시 보정값의 시간적 안정성을 본 데이터로 검증 불가. 캘리브레이션 "수렴" 주장은 향후 실사용 로그가 필요한 **가설**이다. (논문 한계 절 필수.)
2. cold-start의 선형 채택은 "최선의 무지(無知) 추정"이지 정확한 예측이 아니다.
3. 통계 b의 식별성 한계(§2.1)는 영구적 — 추가 N 다양성 확보 없이는 해소 불가.
