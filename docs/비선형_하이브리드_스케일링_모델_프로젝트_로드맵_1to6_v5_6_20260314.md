    ```
    ※ 위 수치는 검증 목표치이며, 실제 값은 is_training_set=FALSE 데이터셋 측정값으로 대체
    ```

- [AI/Data] **통계적 유의성 최종 확인**
    
    - **가설 H1 (멱함수의 우월성)**: 선형(ratio=1) vs Rule-based — paired t-test
        - H1 채택(p<0.05): 멱함수 모델이 선형보다 유의미하게 우수 → P0 목표 달성
        - H1 기각: "비선형 보정의 효과가 통계적으로 입증되지 않음" 한계로 명시
    - **가설 H2 (ML fallback의 기여)**: Rule-based vs 하이브리드 — paired t-test
        - H2 채택(p<0.05): 하이브리드를 최종 권고 모델로 채택
        - H2 기각: **Rule-based 단독을 최종 권고 모델로 채택** — "ML fallback이 category_mean 대비 유의미한 개선을 제공하지 않는다"를 결론으로 논문에 명시
    - ⭐ **최종 권고 모델 결정 기준 (사전 선언, p-hacking 방지)**:
        - H1 ∧ H2 모두 채택 → 하이브리드
        - H1 채택 ∧ H2 기각 → Rule-based 단독
        - H1 기각 → 방법론 전면 재검토 (로드맵 리스크 항목으로 관리)
    - p-value < 0.05 기준 (양측 검정), 검정 대상별 독립 실행
