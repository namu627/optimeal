#### **Week 1-2 (10/1~10/14): PPT 슬라이드 제작**

  

- 프로젝트 배경/목적 및 핵심 문제 의식 (대량 조리 비선형 스케일링 전무한 선행 연구)

- 데이터 수집 과정 (소규모 4,000건 + 대규모 300~350건, 3대분류별 매칭 150쌍)

- **통계 분석 방법론** ⭐ v4.0 반영

- ADR-001: `ratio = a × N^(b-1)` 정의 및 기각안 비교

- ADR-002: 조리방법 3대분류 물리적 근거 + MixedLM 주 전략 채택 근거

- MixedLM 설계식: `log(ratio) = log(a) + (b-1)×log(N) + β₁×Category + u_method`

- 카테고리별 b 추정값 및 신뢰구간 시각화

- **[ADR-008 갱신, E2 참조] ~~3종 모델 비교 MAPE 우위~~ 폐기** → (A) 비선형 *존재* 통계 입증(ΔAIC=−67.13, LRT p=0.032, **식별성 한계 명시**) + (B) **실측 6루프 음성 결과 정직 보고**(선형≈최선, MAPE·WAPE·MdAPE·부호편향 병기) + **캘리브레이션 시스템 기여**(영양사 보정 누적·수렴)

- **CSP Solver 설계** — Hard/Soft Constraint 구조, 기저질환·알레르기·식단가·제철·색감 반영

- **발주 시스템** — 스케일링 → 폐기율 → 최소 발주 단위 흐름

- **자동조리로봇 JSON 명세** — 향후 Central Kitchen 연계 비전 (프로토타입 포함)

- 데모 화면 (식단 생성 → 발주 목록 → 로봇 JSON 출력)

  

#### **Week 3-4 (10/15~10/31): 리허설 및 Q&A 준비**

  

- 발표 리허설 (15분 / 30분)

- **예상 질문 및 답변**:

- "데이터 신뢰성은?" → 정부기관 인증 + 영양사 검수 (is_manually_verified 30% 이상)

- **[ADR-008 갱신, E3 참조]** "AI 모델 정확도는?" → ~~3종 비교 + paired t-test~~ → **"왜 예측 대신 캘리브레이션인가"**: 실측 검증 결과 현 데이터로는 선형이 최선(N 94%가 100 → 멱지수 식별 불가). 이는 약물 알로메트리·공학 6/10법칙과 정합하는 **데이터 인프라 한계**(도메인 불가 아님). 정직한 산출물 = 비선형 *존재* 통계 입증 + 현장 보정을 누적·수렴시키는 캘리브레이션 도구

- "현업 적용 가능성은?" → 영양사 루브릭 4점 이상 평가 + 발주 시스템 MVP 시연

- "왜 Rule-based가 메인인가?" → 150쌍 규모, 해석 가능성, 학술 재현성

- "LLM을 왜 안 썼나?" → 확률적 출력으로 재현 불가, ADR-001 근거

- "왜 X = base×N이 아닌 ratio를 썼나?" → ADR-001: 독립변수 혼동 방지, MixedLM 설계식 호환 ⭐ 신규

- "왜 조리방법을 6종에서 3종으로 줄였나?" → ADR-002: 검정력 확보 + 수분 동태 물리적 근거 ⭐ 신규

- "CSP 실행시간은?" → 7일 < 60초 SLA, 벤치마크 결과 제시 ⭐ 신규

- "ML 분류기는 항상 실행되나?" → 미등록 재료에만 한정. 등록 재료는 DB 직접 조회. 코드에 조건 분기 명시 ⭐ v5.1 신규

- "ML fallback이 왜 필요한가?" → H2 검정 결과에 따라 최종 채택 여부 결정. 기각 시 Rule-based 단독이 최종 모델 ⭐ v5.1 신규

- "영양사 피드백으로 파라미터를 어떻게 업데이트했나?" → ADR-003에 가중 평균 수식 사전 정의. b_new = (b_old×n_old + b_feedback) / (n_old+1) ⭐ v5.1 신규

- "왜 Rule-based가 최종 모델인가 / 하이브리드가 최종 모델인가?" → 5월 H2 paired t-test 결과에 따른 사전 결정 기준(H1∧H2 채택→하이브리드, H2 기각→Rule-based)에 의거 ⭐ v5.1 신규

- **복합점수 수식 변경**: `0.2×방법+0.3×Jaccard+0.5×Cosine` → `0.4×메뉴명유사도(SequenceMatcher)+0.6×재료Cosine`

- **실측 매칭 결과 반영**: ~238쌍(예상) → **171쌍 확정** (습열 82 / 건열 59 / 비가열 30)

- **비가열 한계 명시 의무**: 30쌍으로 구 기준(≥50쌍) 미달 — 논문 한계 절 기술 및 추가 수집 권장

- **재현 스크립트 확정**: `matching_optionB.py` (Python 3.12, pandas 2.x, numpy 1.x, scikit-learn 1.x, difflib)
