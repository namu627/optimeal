## ADR-001 — 멱함수 독립변수 정의 (2026-02-22)

### 결정
**종속변수를 스케일링 비율(ratio)로 정의. 멱함수를 `ratio = a × N^(b-1)` 형태로 표현.**

- `ratio = Y / (base × N)` (실제 투입량 / 선형 예측값)
- `Y` = 대규모 투입량(g), `base` = 소규모 1인분 투입량(g), `N` = 목표 인원수

### 기각안
- `Y = a × (base × N)^b` — b가 "인원수 스케일링 지수"로 해석 불가, MixedLM 설계식과 충돌 → **기각**

### MixedLM 설계식
```
log(ratio) = log(a) + (b-1) × log(N) + β₁ × Category + u_method
고정효과: log(N), Category
랜덤효과: u_method ~ N(0, σ²)
  ← 그룹 구조: ADR-002 v2 기준 (데이터 기반 적응형 — 셀당 n ≥ 10 기준 분리/병합)
  ← 기본: 조리방법 3대분류 (건열/습열/비가열)
  ← 데이터 충분 시: 세부 조리방법 독립 그룹 분리 가능 (볶기, 끓이기 등)
```

### 핵심 의미
- `b < 1`: 대량 시 덜 필요 (양념류)
- `b ≈ 1`: 선형 (주재료)
- `b > 1`: 대량 시 더 필요

### 주의사항
- 엔진 출력 시 역변환 필수: `Y = ratio × base × N`
- ratio 이상치 기준 확정 (2026-03-20): **ratio ∈ [0.2, 3.0]** (도메인 기준 채택. IQR 기준 미채택 — 재현성 문제). 필터링 후 950건 잔존.
- MixedLM B안 확정 (2026-03-20): **b=0.6163** (SE=0.1814, 95%CI [0.261, 0.972], AIC=1262.87, REML, n=607). OLS 대비 ΔAIC=-67.13 (n=950 동일 기준)으로 랜덤효과 도입 정당성 확보.

## ADR-002 — 통계 전략: 대분류 병합 + MixedLM (2026-02-22, v2: 2026-03-06, v5: 2026-03-14)

### 결정
**조리방법 3대분류 병합 → MixedLM 주 전략 순차 적용 (대안 C 채택)**  
**v2 추가: 데이터 기반 적응형 그룹 전략 도입 (셀당 n ≥ 10 기준 사전 선언)**

| 단계 | 내용 |
|------|------|
| Step 1 | 조리방법 6종 → 3그룹 병합 (기본값, 셀당 N 확보) |
| Step 2 | EDA 후 셀당 n ≥ 10 충족 조리방법은 독립 그룹 분리 (ADR-002 v2) |
| Step 3 | MixedLM을 주 추정 전략으로 사용 |
| Step 4 | curve_fit은 N이 충분한 셀에 한해 보조 시각화용만 사용 |

### 조리방법 3대분류
- **건열**: 볶음, 구이, 부침 (표면 수분 증발, 마이야르 반응)
- **습열**: 국·찌개, 찜, 조림, 삶기 (국물 전체 수분 동태)
- **비가열**: 무침, 샐러드 (수분 증발 없음)

### 병합 근거
- 물리·화학적 특성 기반 분류 → 논문 정당화 가능 ("통계적 편의"가 아닌 "수분 동태 기반")
- 셀당 평균 5쌍 → 10쌍 이상으로 증가 (150쌍 기준)
- 그룹 내 분산은 MixedLM 랜덤효과로 흡수

### [ADR-002 v2] 데이터 기반 적응형 그룹 전략 (2026-03-06 추가)

#### 배경
- 초기 대규모 레시피 약 80건 확보 시: 조리방법별 레시피 수가 5건 이하인 경우 존재 → 과적합 방지를 위해 3대분류로 병합
- 대규모 레시피 약 400건으로 확대 시: 볶기·끓이기 등 일부 조리방법이 독립 분리 기준 충족 가능

#### 분리 기준 (사전 선언 — p-hacking 방지)
> **이 기준은 데이터를 확인하기 전에 선언한다. 데이터를 본 후 기준을 변경하면 p-hacking과 동일한 비판을 받는다.**

- **기준**: 셀당 예상 관측 수 = 조리방법별 레시피 수 ÷ 재료 카테고리 수(5종)
- **n ≥ 10**: 독립 랜덤효과 그룹으로 분리 (`SEPARATE`)
- **n < 10**: 상위 3대분류로 병합 유지 (`MERGE`)

#### 적용 시점
- 3월 4주차(3/25) EDA 완료 직후 조리방법별 관측 수 집계
- 결정 결과를 본 문서(ADR-002 v2)에 즉시 기록
- MixedLM 코드의 그룹 변수를 확정된 구조로 수정

#### 한계 명시 (논문 방법론 섹션 필수 포함)
> "조리방법별 랜덤효과 그룹은 사전 선언된 셀당 n ≥ 10 기준에 따라 분리/병합하였다. 최종 그룹 수가 k개로 결정되었으며, 그룹 수가 5개 미만인 경우 랜덤효과 분산 추정의 신뢰도에 제약이 있음을 인정한다 (Maas & Hox, 2005)."

### 교차 검증 전략 (ADR-002 v2 추가)
- **GroupKFold (5-Fold)** — 일반 KFold 사용 금지
- 분할 단위: 레시피 쌍(`base_recipe_id`) 기준
- 동일 메뉴의 소규모-대규모 쌍이 train/test에 동시 포함될 경우 data leakage 발생
- 그룹 변수: `base_recipe_id` 또는 `menu_name`

### [ADR-002 v5] 레시피 매칭 유사도 수식 변경 (2026-03-14)

#### 결정
**가중 Jaccard 제거 → 복합점수 = 0.4 × 메뉴명유사도 + 0.6 × 재료Cosine 채택**

#### 변경 근거
소규모(1인분)와 대규모(100인분) 이종 DB의 재료 기록 상세도 불균형으로 가중 Jaccard 분모가 체계적으로 과대평가됨. 전체 583건 임계값 없이 전수 스캔 결과 복합점수 최댓값 0.57 — 임계값 조정으로 해결 불가능함을 실증.

| 구성 요소 | 가중치 | 설명 |
|---|---|---|
| 메뉴명유사도 (SequenceMatcher) | 0.4 | 동일 메뉴 우선 포착. 이종 DB 표기 차이 부분 흡수 |
| 재료 Cosine (binary 벡터) | 0.6 | 기록 상세도 불균형에 강건. 공유 재료 비율 반영 |
| 가중 Jaccard | 제거 | 이종 DB 체계적 편향 실증 → 제거 |

#### 유지 사항
- FR-03 임계값 체계: ≥0.7 자동 태깅 / 0.6~0.7 수동 검토 / <0.6 제외
- group_type 1단계 필터 유지
- 수동 검수 30% 의무 유지
- 정규화 맵 v4.0 + 보완 51건 적용

#### 실측 매칭 결과 (2026-03-14)

| group_type | ≥0.7 자동 | 0.6~0.7 수동 | 소계 |
|---|---|---|---|
| 습열 | 35 | 47 | 82쌍 |
| 건열 | 26 | 33 | 59쌍 |
| 비가열 | 10 | 20 | 30쌍 |
| **합계** | **71** | **100** | **171쌍** |

> 비가열 30쌍은 ADR-002 v4 기준(각 ≥50쌍) 미달. 논문 한계 절 명시 의무.

### [ADR-002 v3] 영양사 피드백 기반 세부 조리방법별 b값 보정 공식화 (2026-03-07 추가)

#### 결정
**`estimation_method = 'nutritionist_feedback'` 값을 공식 허용값으로 추가. 피드백 보정 b값과 통계 도출 b값의 역할을 명확히 분리한다.**

#### estimation_method 전체 허용값 (v3 기준)

| 값 | 도출 방법 | 역할 |
|---|---|---|
| `mixedlm` | MixedLM 통계 분석 | 방법론적 정당성 담당 |
| `curve_fit` | scipy curve_fit 보조 | 시각화·비교용 |
| `category_mean` | 카테고리 평균 fallback | 미등록 조합 대체 |
| `nutritionist_feedback` | 현업 영양사 피드백 보정 | 현장 적용 가능성 고도화 |

#### 룩업 우선순위 (Rule-based 엔진 코드에 반드시 구현)
1. `(cooking_method_id × ingredient_category)` — 세부 조리방법 피드백 보정값
2. `(group_type × ingredient_category)` — 3대분류 통계 도출값
3. `ingredient_category` 평균 — category_mean fallback

#### 학술적 위상 구분
- 통계 도출 b: 논문 방법론의 핵심 근거. p-value, 신뢰구간 보고 의무.
- 피드백 보정 b: 통계의 k=3 한계를 실무 전문가 지식으로 보완. 논문 한계 절에 명시 의무.
  > "피드백 기반 b값은 재현 가능성이 통계 기반 b값보다 낮으며, 현업 전문가 지식에 의한 보완임을 명시한다."

#### 근거
- k=3 문제로 인해 3대분류 수준 σ² 추정 신뢰도에 제약 존재 (Maas & Hox, 2005)
- 영양사 피드백은 통계가 포착하지 못하는 현장 도메인 지식(조리 용량 한계, 조리 순서 효과 등)을 반영
- `parent_coefficient_id` 체인으로 통계 b → 피드백 b 계보 추적 보장

## ADR-003 — 파라미터 업데이트 수식 및 클리핑 전략 (2026-02-23)

### 결정
**단순 이동 평균 업데이트 + 2단계 독립 클리핑 채택**

### 업데이트 수식
```python
b_new = (b_old × n_old + b_feedback) / (n_old + 1)  # 단순 이동 평균
```
- EMA(지수이동평균) 기각: α 선택 정당화 어려움, 피드백 5회 고정 소규모에 부적합

### b_feedback 역산 수식
```python
ratio_adj = (실제 투입량 + Δ_g) / (base_amount × N)
b_feedback = log(ratio_adj / a_old) / log(N) + 1
```

### 2단계 독립 클리핑 (멘토링 제안 기각 후 채택)
| 단계 | 대상 | 방법 |
|------|------|------|
| **1단계 (입력)** | `Δ_g` | IQR 기반 이상치 제거 |
| **2단계 (출력)** | `b_new` | 도메인 지식 기반 범위 클리핑 |

> **멘토링 제안 기각 이유**: `b_feedback` 자체에 ε 클리핑 적용 시  
> (1) 정상 피드백도 차단 가능, (2) 업스트림 `Δ_g` 오류 미탐지, (3) 이중 방어 부재

## ADR-004 — ingredient_amount 불확정값 처리 (2026-02-25)

### 결정
**`amount_type` 컬럼 신설로 수량 표기 상태를 명시적 구분 (Option A 채택)**

### 컬럼 정의
| 컬럼명 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| `ingredient_amount` | DECIMAL(10,3) NULL | 조건부 | MEASURED일 때만 수치 입력 |
| `amount_unit` | VARCHAR(20) NULL | 조건부 | g, ml 등 단위 |
| **`amount_type`** | **ENUM** | **필수** | **MEASURED / DISCRETIONARY / UNKNOWN** |
| `amount_note` | VARCHAR(100) | 선택 | 원문 표기 보존 ("약간", "적당량" 등) |

### amount_type 정의
- `MEASURED`: 수치 확정
- `DISCRETIONARY`: 약간·적당량 등 재량 조절
- `UNKNOWN`: 원본 데이터 자체 누락

### 스케일링 처리 방침
- `DISCRETIONARY`: 별도 규칙(예: 인분수^0.7) 적용 또는 제외, 분기 조건 코드에 명시
- `UNKNOWN`: 스케일링 대상에서 제외

### 기각안
- NULL만 사용: 데이터 누락 vs 재량 표기 구분 불가 → 기각
- 0으로 채움: "재료 없음"으로 오인 → 기각
- 완전 제거: 레시피 완전성 훼손, 비교 연구 불가 → 기각

## ADR-006 — Rule-based 엔진 폐기, 1D ResNet 스케일링 엔진 채택 (2026-05-19)

### 결정
**Rule-based 룩업 엔진(`fallback.py` D-3/D-4/D-5)을 폐기하고 1D ResNet으로 전체 스케일링을 대체한다.**
**FR-06 (ML 분류기) / FR-07 (ML 예측기)도 함께 폐기. NN이 ML 모듈 책임을 통합한다.**

- 학습 타겟: `Y = base × N^b_feedback` ← b_feedback은 영양사 50건 합의 보정값 (≈0.74)
- 입력 텐서: (B, 3, 30) — log(base) + category_id + valid_mask
- 아키텍처: stem(Conv3→32) → ResBlock(32→32) → ResBlock(32→64) → Flatten + log(N) → FC(128) → FC(30)
- 데이터 확장: N ∈ {10, 20, 50, 100, 150, 200, 300} 7종 (205 레시피 → 1435 샘플)
- 분할: GroupKFold(5, 그룹=small_recipe_id) — data leakage 방지

### 전환 이유 (3가지)

**1. MixedLM 통계 b가 MAPE 기준으로 실패**
- baseline_result.csv (n=342) 기준: 선형 32.68% vs MixedLM(b=0.6163) 34.31% — **1.63%p 더 나쁨**
- 원인: MixedLM은 `log(ratio)` 잔차 제곱합 최소화 모델 — MAPE 최소화와 동치 아님
- 결과: 통계 b는 *비선형 관계의 존재*(LRT p=0.032, ΔAIC=-67.13)만 입증, 정확도 주장 불가

**2. 영양사 피드백 b의 MAPE 비교가 구조적으로 불가**
- 피드백 수집 구조: `Y_final = Y_engine + Δ_g` → target이 엔진 출력에 종속
- `MAPE = |Δ_g| / Y_final`은 예측 정확도가 아닌 *영양사 수정량 크기*를 측정 (닻내림 + 반사실 문제)
- 결과: Rule-based 룩업 엔진이 학술적 정확도 주장 수단을 모두 상실

**3. Rule-based의 일반화 한계**
- (group_type × ingredient_category) 셀별 단일 b 조회 — N의 연속 일반화 없음
- 미등록 조합은 category_mean fallback 의존
- NN은 N을 연속 입력으로 받아 임의 인원수에 일반화 가능

### 학술적 위상 분리 (논문 방어용)

| 단계 | 책임 | 산출물 |
|------|------|--------|
| 통계 (MixedLM) | 비선형 관계의 *존재* 증명 | b=0.6163, LRT p=0.032, ΔAIC=-67.13 |
| 영양사 피드백 | 현장 합의 b 도출 | b≈0.74, 50건 98% 승인 |
| 1D ResNet | b 표준의 *임의 레시피 일반화* | nn_model.pt, MAPE TBD (5/19 학습 예정) |

### 합성 데이터가 아닌 이유
- `Y = base × N^b_feedback`의 b_feedback은 실측 피드백에서 도출된 매개변수
- N 확장은 도메인 합리적 범위 내 결정론적 확장 — 분포 가정 없음
- 분포 가정 기반 생성(GAN 등)이 아닌 도메인 매개변수 적용 → **측정 기반 파생 데이터**

## ADR-007 — NN_v2 + lookup 하이브리드 채택 (2026-05-20)

### 결정
**ADR-006의 "NN 단일 엔진" 결정을 부분 수정한다. 운영 엔진을 다음 하이브리드 분기 구조로 채택한다:**

```
predict_hybrid(group_type, ingredient_category, base, N):
    if (group_type, ingredient_category) in b_feedback_table:
        # 학습 데이터에 셀이 있음 → NN_v2 추론
        return DeepSetsContext.predict(...)
    else:
        # 미커버 셀 → lookup category_mean fallback
        b = mean(b for (g, c), b in b_feedback_table if c == ingredient_category)
        return base × N^b
```

### 채택 근거

`docs/for_reports/nn_results_analysis_20260520.md` §9의 실험 결과:

| 평가 | v1 (ADR-006, Conv1d/결정론) | v2 (DeepSets/noisy) |
|---|---|---|
| 5-Fold NN MAPE | 39.62% ± 14.75% | **19.65% ± 1.34%** |
| 5-Fold Δ (LK−NN) | (비교 불가) | **+2.01%p (NN 우위, 5/5 fold)** |
| LOCO Δ (LK−NN) | −124.66%p | **−25.99%p (5배 축소, 여전히 lookup 우위)** |

- 학습 데이터에 셀이 포함된 in-distribution 추론은 NN_v2가 lookup을 능가 → NN 사용 정당
- 셀이 누락된 out-of-distribution 외삽은 lookup이 우위 → 미커버 셀은 lookup fallback
- b_feedback 클러스터링(0.6755~0.7688)이 좁아 category_mean이 진짜 b의 강한 추정치임

### 학술적 위상 (논문 보고 가능 표현)

> "1D ResNet 슬롯 위치 기반 모델은 hold-out 셀 외삽에서 lookup 대비 평균 124.66%p 열세였으나,
> permutation-invariant DeepSets 아키텍처와 노이즈 학습 데이터(σ=0.05)를 도입한 v2 모델은
> 5-Fold CV에서 lookup 대비 평균 2.01%p 우위를 달성하였다. LOCO CV에서는 여전히 lookup이
> 평균 25.99%p 우위였는데, 이는 b_feedback 셀별 분포가 매우 좁아(0.6755~0.7688) 카테고리
> 평균 fallback이 강한 baseline임에 기인한다. 따라서 최종 운영 엔진은 학습 셀 내 추론은
> NN_v2, 미커버 셀 외삽은 lookup으로 분기하는 하이브리드 구조를 채택한다."

### 한계 명시 (논문 한계 절 필수)

1. 학습 타겟이 결정론적 합성치 + 작은 가우시안 노이즈(σ=0.05)이며, 실측 대규모 레시피와 정합성 미검증
2. 절대 MAPE 수치는 노이즈 σ 선택에 의존 — 보고 시 σ 명시 필수
3. 외삽(미커버 셀)은 lookup fallback에 의존하므로 NN 단독으로 일반화 불가
4. b_feedback의 좁은 클러스터링 자체가 영양사 50건 5회차 피드백의 수렴 결과이며, 다른 도메인 데이터에서 동일하리라는 보장 없음

## ADR-008 — 예측 엔진 포기, 캘리브레이션 가능 의사결정 보조 도구로 학술 위상 재정의 (2026-06-28)

> 상태: ✅ 승인 (2026-06-28, 권성민·팀·지도교수 합의). 초안: `docs/adr-008_draft_q3_calibration.md` (검토본 v0.2, 2026-06-27).
> 근거: `wiki/analysis/realdata_engine_validation.md`(실측 6루프), `wiki/analysis/scaling_domains_survey.md`(유사 도메인 서베이), `wiki/design/calibration_direction.md`.
> 관계: ADR-006·007의 *정확도 주장* 부분 철회, *구조*는 보존. NFR-01 재정의 동반(PRD v1.6/요구사항 v1.5 확정 반영).

### 배경

ADR-006·007은 모듈 2를 "선형 대비 정확한 비선형 스케일링 엔진"으로 위치시켰으나, 2026-06-27 실측 6루프 검증에서 다음이 확정되었다:

1. 기존 모든 NN/lookup MAPE는 **합성 타겟 대 합성 타겟** 비교였다 (학습 타겟 `Y=base×N^b_feedback`이 결정론 공식 → NN은 공식 모방, MAPE는 근사 오차이지 예측력 아님).
2. 실측 Y(`df_B.csv`)로 평가 시 **선형이 사실상 최선** (실측 OOS MAPE: 선형 65.4%, 유연 GBM 66.8%, OOS R²=0.06).
3. **N 식별 불가**: 607행 중 570행(94%)이 N=100. N=80 11행 제거만으로 b가 0.625→0.761, 95%CI가 1.0(선형) 포함.
4. **분산의 96%가 (group_type×category) 셀로 설명 안 됨** — 레시피별/재료별 고유 보정값, 어떤 피처로도 예측 불가.
5. **메트릭 착시·운영 위험**: MAPE를 낮추는 모델(카테고리 b)은 WAPE 꼴찌·−20.8% 과소예측(현장 결식 위험). MAPE·WAPE 동시 우위 모델 부재.
6. **범위 단서 — "도메인 불가"가 아니라 "현 데이터로 불가"**: 멱함수 양 스케일업+랜덤효과는 약물 알로메트리(b≈0.75)·공학 6/10 비용법칙(b≈0.6)·생물 알로메트리(b=0.75)가 푸는 표준 구조. 본 음성 결과는 스케일링 문헌과 정합하는 식별성 한계(N 변동 부재).

### 결정

**(A) 통계 기여**: 대량조리 스케일링에 **비선형 관계가 통계적으로 존재**함을 MixedLM으로 입증(b≠1, ΔAIC=−67.13, LRT p=0.032). **식별성 한계를 방법론에 명시**: b 점추정은 N=100 집중(94%)으로 식별 제약, 방향성·존재는 지지되나 크기의 신뢰구간은 넓음.

**(B) 시스템 기여**: 예측이 현 데이터로 불가능한 도메인에서, **영양사 보정을 정답으로 누적·수렴시키는 human-in-the-loop 캘리브레이션 도구**를 설계·구현.

**엔진 구조 재정의** (예측기 → 캘리브레이션 기판):
```
[Cold-start] 초기 추정 = 선형(b=1)   ← "예측"이 아닌 "출발점", 신뢰도 플래그 동반
   → [영양사 보정 Δ_g 입력]
   → [캘리브레이션 레이어] (업장×레시피×재료) 보정 누적, ADR-003 SMA/EMA 갱신
   → [반복 사용] 해당 업장 실측으로 수렴
```
- cold-start 기본값 = **선형(b=1)** (실측 최선, 무편향, 과소예측 위험 없음). 카테고리 b는 옵션(−20.8% 과소편향 표기).
- 캘리브레이션 단위: 기본 (레시피×재료), 멀티 업장 확장 시 (업장×레시피×재료).
- **CBR 참고 표시**: 유사 재료집합 과거 레시피의 영양사 실보정량을 *참고 이력으로 표시*(출처·일시 명시, 자동 적용 금지). decision-support이며 닻내림 위험은 분포/범위 제시로 완화.

**NN·하이브리드 위상 강등**: NN v1/v2·ADR-007 하이브리드는 **운영 정확도 주장에서 제외**, 실험 기록·비교군으로 보존. "NN이 lookup 대비 +2.01%p 우위" 등 정확도 표현은 합성 타겟 한정 명시·실측 주장 철회. 구조·코드 삭제 안 함.

**평가 지표 재정의**:
| 단계 | 주 지표 |
|------|---------|
| Cold-start | 실측 OOS에서 선형 대비 **동등/약우위 정직 보고**(과장 금지). MAPE·WAPE·MdAPE 병기 + 부호편향. |
| 캘리브레이션 | 회차별 **수렴 속도, 영양사 보정량(Δ_g) 감소 추세, 승인율**. |

| NN 합성타겟 MAPE 그대로 논문 보고 | 순환 검증. 독립 ground truth 부재. |
| 현 NFR-01 유지 + [0.5,2.0] 필터로 32.68% 보고 | ADR 확정 필터 [0.2,3.0] 위반. 헤드라인이 필터 선택에 의존. |
| "도메인 자체가 학습 불가"로 결론 | 서베이 반증: 알로메트리·6/10법칙은 동일 구조 학습. 정확한 진술은 "현 데이터 인프라로 불가". |
